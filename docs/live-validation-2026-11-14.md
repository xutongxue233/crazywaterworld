# 2026-11-14 新增自动化真实账号验证

本次在用户明确要求后，以已有 S4、24 级角色连接真实游戏。以下仅记录已观察到的服务器结果，不把离线模拟、计划输出或发送成功视为完整实测通过。账号凭据、原始协议日志及用量账本不纳入仓库。

## 执行方式

- 预先注册活动与舰队观察器，使用单个游戏连接串行执行；没有启动已保存的整套挂机循环。
- 调用实际自动化模块，配置只在内存覆盖，不保存测试开关。请求边界每次仅允许一个确定请求名、参数和发送次数的写操作。
- 使用原账号持久用量账本，发送前占用，业务状态确认后核销；没有清空历史记录或还原旧账本。
- 全局钻石消费始终关闭；没有购买、加速、抽卡或攻击其他玩家。

## 协议分析工具修复

核对真实协议时发现 `tools/describe.mjs` 把嵌套消息命名空间写死为旧压缩变量 `tf.protocol`，第 76 版使用 `tk.protocol` 时会漏报字段。已改为匹配合法 JavaScript 标识符，并补充旧版、新版、重复消息、单字段消息及超凡英雄实际响应回归；该问题影响协议描述工具，不是服务器没有这些字段。
