## 与截图不能完全照搬的规则

- **联盟募兵**实际发送 `FinishGuildOrderRequest`，和原联盟订单是同一动作。用户日限0仅表示不加额外限制；真实赛季／等级上限仍有效。自动帮助关闭不影响已获援助领取和独立主动求助。贡献模式只选当前赛季材料，不因未解锁而改用另一赛季材料。
- **联盟商船**当前配置要求18级；S6起增加刷新批次，不能把08/11/14/17/20/23写成所有赛季固定规则。水姆币是奖励最低门槛，不是支付费用。没有直接开航请求，时间设置只能限制申请船长的最早时间；末日兜底必须先收到服务器真实活动结束时间。
- **工事捐赠**不创建、拆除或完成工事，不兑换或购买缺料。工事材料未选时可沿用联盟互助允许材料；两处皆空就不捐赠。
- **英雄活动抽卡**的 `HeroRaidPrizeRequest` 消耗英雄副本抽卡券，协议没有免费次数。当前模块只做订单和已达标奖励，不新增虚假的免费抽卡配置。
- **海商王**远端价格仍可能是带折扣的估值，到港及发送前重新核验，截图中的“5亿”不是保证。利润上限单位为商会币，50000万元对应500000000；0不加额外利润限制。新增指针日限默认28（0禁止使用），购买默认关闭、模块钻石预算0禁止购买；只补有效方案的缺额，受游戏日购买上限及全局预算共同限制。`TradeBuySpeedItemRequest({buyNum})` 的购买次数、回执和后续库存共同确认，未知结果不反复购买。
- **硅矿**除等级外还受赛季开放条件限制。奖励由服务器自动发放，`ChipMineRewardRequest`只是读取额度；首轮15分钟采集前不可随意撤回。安全玩家按完整昵称，安全联盟按实际`guildIdx`编号（1–999），矿位协议不提供联盟名称或玩家UID。追击只针对游戏黑名单内、已通过本人胜利战报核实的目标，窗口相对三日奖励周期重置计算，不能误当每15分钟重开。首次接入缺少当日基线时，保守把当前周期累计计入今日，可能少派，不会虚构今日计数。

## 接线、持久化与资源边界

1. 所有新增参数沿用按账号自动保存，包含三支硅矿舰队的嵌套设置、时间和名单；导入、重新载入、刷新和切号沿用原版本校验。关闭总开关保留子项选择。旧账号显式开关不重置。
2. 联盟商船和工事同时要求联盟总开关；常驻新模块接管时同功能旧任务避让。不差钱商人直接复用周订单开关，不重复登记任务。新增消费默认关闭；截图里开启的状态不写入真实账号。
3. 同账号动作经现有挂机／手动队列串行执行；推送和配置修改只唤醒检查，不在推送回调并发写入。普通硅矿10分钟、有效追击配置2分钟复查，相关推送可提前唤醒。
4. 工厂总开关仍决定是否生产。募兵和红船备料可独立于通用“优先需求”配置，工厂到期子轮重新调查当前需求，达限／已上船／未知提交后不沿用旧订单。商人和英雄活动的需求仍遵守普通工厂策略。
5. 周订单、贸易港和居民订单保留量与新增需求共同计算；消费前重读库存、真实状态、身份、开关、时间和预算。舰队占用及待确认汽油与城战、情报、货轮、世界Boss、海盗共用，硅矿默认在优先级最后。
6. 发送前持久预占次数和预算，业务回执与真实状态确认后核销。超时、断线、重启或跨日不能将未知结果当作未发送；只有确定未发或明确拒绝才释放。钻石消费还需要全局授权及对应模块预算。
