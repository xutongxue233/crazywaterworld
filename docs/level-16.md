# 16 级玩法指南

刚升到 16 级，最先值得做的是挑战强化石副本，以及找世界海盗拿第一块农田需要的有机土壤。以下门槛取自 74 版游戏配置；建筑、舰队和首杀进度以当前账号为准。

| 想做什么 | 从哪里开始 | 条件和收益 |
| --- | --- | --- |
| 拿第一笔强化石 | **挑战 → 试炼副本** 中找到强化石副本，点击下一关 | 第 1 关配置战力为 12.5 万，首通奖励含 2,800 强化石。首通前可扫荡 0 次。通关后可在 **挂机 → 挑战** 开启免费扫荡，每个副本每天第一次免费。如果最高通关仍是第 1 关，该次扫荡给 1,400 强化石和 10 个加速器。 |
| 给农田备土 | **活动 → 海盗首杀** 中选择地图目标和舰队，手动派遣 | 第一块农田要 100 有机土壤。可在列表查看各类目标的首杀奖励。单队出征消耗 300 汽油。日志分别记录请求、战斗结果和个人首杀确认。 |
| 为远征舰队首次编队 | **活动 → 海盗首杀 → 远征舰队编队** | 已建成远征舰队且阵容为空时，可以预览闲置英雄并保存。编队保存后再看世界地图是否已登记该舰队，舰队闲置且有耐久才能出征。 |
| 生产种子 | **挂机 → 海面** 开启「空位建造」「工厂排产」「为待建建筑补产材料」 | 16 级可建选种厂，需要 2,400 金币、10 建筑蓝图和 6 粗铁。金币和蓝图备齐后，1 级金属厂可按缺口补粗铁，每个消耗 40 废金属和 4 淡水。订单优先。选种厂 1 级产小麦种子，升到 2、3、4 级依次开放玉米、土豆、番茄种子。 |
| 穿戴与强化装备 | **英雄 → 英雄装备** | 选择英雄可预览空槽及可穿戴的闲置装备。单件强化的按钮显示升一级所需强化石，点击后核对服务端等级变化。 |
| 领取联盟福利 | **日常 → 联盟**，或开启 **挂机 → 联盟 → 领取联盟福利礼包** | 入盟后可查看成员求助所需材料。礼包免费，领取结果以服务器返回的奖励和领取时间为准。 |
| 减少种田时间 | 控制台 **英雄 → 英雄任命 → 查看职位** | 16 级新增「种田时间」职位。点「一键任命」会按游戏内优先顺序重新分配可用英雄，其他职位也可能调整。 |
| 查看世界资源田 | 控制台 **单次操作 → 资源田** | 16 级开放世界、舰队码头和远征舰队建筑。报告可以查看占地和舰队状态。建筑竣工和拥有一支可出征的舰队是两个条件。 |

「英雄主题副本」和「海上风采大赛」也有 16 级门槛，是否开放取决于当期活动。这两个限时玩法仍需在游戏内参与。回游戏前可先暂停托管，避免顶号。

**17 级有什么变化？** 游戏配置将周活动和海商王的入口设在 17 级。16 级账号也可能已经收到周活动目录，具体奖励能否领取以服务端进度为准。控制台支持周战令领奖、周抽奖免费礼包和累计次数奖励。周订单按缺口备料，由玩家手动交单。海商王与贸易港有各自的玩法入口。

17 级建成装备厂后，可在「挂机 → 装备制造」分别开启收取与自动制造。自动制造优先补闲置装备中数量较少的部位，每轮至多一件，并保留 10,000 金币；游戏内自动锻造开启时会跳过。

**联盟后续玩法：**「挂机 → 联盟」可开启联盟订单提交，每轮最多一单，先保留周订单、贸易港和居民订单用料。联盟情报按配置在 18 级开放，情报领奖与派舰、低耐久维修各有开关，默认关闭。出征需要至少 20% 战力余量和 80% 耐久，派遣与维修后至少保留 10,000 汽油。

**23 级海兽培育、28 级博物馆：** 建成对应建筑后，可在挂机页开启收取与继续生产／探险。海兽每轮最多培育一只，品质上限橙色，保留 10,000 金币；博物馆每轮最多派一队，按配置检查队伍数量、英雄条件与材料，先留足其他订单用料。探险到期结算和领取奖励是两次请求，由同一个收取开关完成；只有确认领奖后才释放英雄。以上开关均默认关闭。
