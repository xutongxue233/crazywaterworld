## 快速开始

需要 Windows 和 Node.js 20.11 或更高版本。默认流程从电脑版微信的游戏缓存读取协议和配置，请先在微信里打开一次《疯狂水世界》。添加抖音账号还需要在同一台电脑上登录电脑版抖音。

```powershell
git clone https://github.com/xutongxue233/crazywaterworld.git
cd crazywaterworld
npm ci
npm run sync-config
npm start
```

`npm start` 会先构建界面，再在 `http://127.0.0.1:17321/` 启动控制台。`.\start-console.cmd` 在 `http://127.0.0.1:17323/` 启动控制台，不自动打开浏览器，显示地址并持续输出运行日志；`.\start-console.cmd url` 只输出地址并保持窗口，不运行后台；`.\start-console.cmd status` 只检查抓包证书状态。

1. 打开本地控制台，进入 **账号**，选择 **从电脑微信添加** 或 **从电脑抖音添加**。提示正在采集后，从对应客户端重新进入游戏，核对日志中的角色验证结果。
2. 在 **游戏配置** 设定要运行的项目、资源保留和预算；可先用 **只读预览** 查看当前计划。保存配置不会启动挂机。
3. 进入 **挂机** 开启所需模块并开始运行。首次可将轮数设为 `1`，核对日志与收益；`0` 表示持续运行。首杀推进、主线推关和联盟互助有各自的启动入口。
4. 自己上号前点 **暂停托管**，工具会断开游戏连接。轮数设为 `0` 并开始挂机后，可以关闭全部网页；任务由 Node 后台进程执行，CMD 启动窗口继续显示带时间、账号与级别的日志。请保持启动窗口打开、电脑唤醒和网络连接；关闭启动窗口或按 `Ctrl+C` 会结束进程。重新打开网页可查看后台状态与最近 400 条日志。

> 请只用自己的账号测试。自动化操作会改变游戏内的资源和进度，使用第三方工具有账号处罚风险。采集凭证会临时更改当前 Windows 用户的代理和证书设置。账号凭证与账号导出文件含登录信息，请留在本机。

## 运行方式

| 入口 | 行为 |
| --- | --- |
| `npm start` | 构建界面并启动控制台，默认端口 `17321` |
| `.\start-console.cmd` | 启动控制台，不自动打开浏览器，输出地址与实时运行日志，端口 `17323` |
| `.\start-console.cmd url` | 只输出地址 `http://127.0.0.1:17323/` 并保持窗口，不启动控制台 |
| `.\start-console.cmd status` | 只检查抓包 CA 状态，不启动控制台 |
| `$env:CW_PORT='17324'; npm start` | 指定控制台端口 |
| `$env:CW_NO_BROWSER='1'; npm start` | 启动控制台但不自动打开浏览器 |

控制台只监听 `127.0.0.1`，没有登录校验。手机访问需要自行搭建带鉴权的隧道，不要直接暴露到公网。

## 添加账号与抓包

添加账号时，工具会临时安装当前用户测试 CA、启用系统代理并监听登录请求，采集结束后自动还原代理并移除本次安装的证书。CA 文件和代理备份保存在项目的 `certificates/`，停止抓包并成功移除证书后会删除本次生成的文件；明确选择保留 CA 时保留。

- 抓包期间可能把正在玩的游戏顶下线，采集完成后建议重新登录。
- 未连接的账号也可在礼包兑换时自动登录，但同样可能顶号。
- 旧版本曾在项目上一级留下 `certificates/`，升级后可手动删除一次。
- 抖音单独采集可运行 `npm run capture:douyin`。

### 手机号登录

先在游戏社区/小程序绑定手机号，并设置 APP/益世界账号的登录密码。控制台 **账号 → 手机号登录** 支持账号密码或短信验证码登录益世界 ewan 账号 SDK，再换取游戏网关凭证。

首次使用请点 **登录并预览**，确认返回的 openId 是已有角色再保存；如果它是新的 openId，保存后会新建一个空账号，不要直接覆盖。密码只用于当次请求，不写入任何文件；待保存凭证只在内存保留 10 分钟。工具不代替绑定手机号。

登录还绑定 APP 的 `di/oi/devicecode` 设备标识。工具默认读取本机 `data/ewan-device.json`；APP 重装或换设备后，如果返回“用户名或密码错误”，需要按文档重新导入这份设备档案。

CLI 等价入口：

```powershell
$env:CW_PHONE='手机号或账号'
$env:CW_PHONE_PASSWORD='登录密码'
node src/app.mjs accounts login-phone --probe   # 只看登录响应字段
node src/app.mjs accounts login-phone           # 预览游戏 openId，不保存
node src/app.mjs accounts login-phone --save --yes

# 已拿到短信验证码时（控制台可直接点“发送验证码”）
$env:CW_PHONE='153xxxxxxxx'
$env:CW_PHONE_CODE='123456'
node src/app.mjs accounts login-phone --code "$env:CW_PHONE_CODE" --probe
```

协议细节和限制见 [手机号登录分析](docs/phone-login.md)。

### 基地与养成

| 功能 | 行为与配置 |
| --- | --- |
| 建筑与工厂 | 收成品、竣工、空位建造、升级及建材备料；可禁用建筑或工厂、保留蓝图、限制每轮建造与升级次数。按订单缺口排产，队列中和待收产品计入备料 |
| 工厂需求 | 调整需求来源顺序，移除来源即停止为其安排；支持指定来源加速、库存水位和加速器保留。可协作调整已开启的游戏原生自动生产，保留已有队列，调整间隔至少 60 秒 |
| 农田与港口 | 自动选种与自定义作物互斥，自定义按所选顺序和库存水位种植，收割独立控制；港口可限制每日装货批次，收货不占额度 |
| 居民订单 | 按禁用材料、最低经验/金币、每日上限筛单；12 级后可刷新不合条件的订单。在建筑一览仍可逐张手动提交，发送前重新检查订单和库存 |
| 采集与钓鱼 | 潜水、拾荒、原料漂浮物、藏品宝箱、钓鱼和三类工具养成分别控制；自动采集要求对应玩法达到 2 级。可设满鱼仓时处理图鉴；潜水后使用已有钥匙，每轮最多一把 |
| 随机事件 | 为已支持事件设置默认选项；海上资源补给固定选择建造居民房，居民离开固定选择让其离开 |
| 英雄与阵容 | 手动升级、升星、升技能、任命、补装备空槽及单件强化；自动养成可选英雄、目标等级/星级、经验保留和万能碎片权限。推荐阵容取自游戏内攻略，点击才换阵，出征中的舰队不能换阵 |
| 藏品养成 | 自动激活藏品、升星、提升藏品大师等级和套装等级。可限定激活/升星/套装品质、目标星级、目标大师等级、金币保留和每日套装金币预算；升星可用万能碎片补足，激活只使用普通碎片。只消耗现有碎片、经验与金币，不购买、不使用钻石，结果未知时保留记录 |
| 海兽培育 | 23 级建成培育室后，可按所选品种和品质上限领取、培育、投喂、进阶，单独控制万能基因与放生 |
| 博物馆 | 28 级建成后，按所选地图与英雄条件派队，支持 1–3 倍时长、按材料匹配倍数、指南每日上限和升级。到期先结算再领奖，确认后继续派队 |
| 装备制造与锻造 | 保留 17 级装备厂手动制作、领取和原有收取/续产开关；详细锻造配置可选工厂、按勾选顺序选择可满足的配方，设置材料/万能材料/金币保留和每日金币、次数预算 |

周订单、贸易港和居民订单的材料会参与预留。周订单未齐时可以交付已备齐的居民单，再安排补产；周订单齐备后按其提交开关处理。联盟订单默认关闭，每轮最多一单，只使用扣除其他订单预留后的现有材料，不额外为联盟订单排产。新旧海面、港口、基地和锻造流程共用材料与金币扣款检查，手动居民交单同样受保护：先核实订单、养成进度或队列等业务结果，再读取完整库存结算，补产或金币收入不再因余额高于历史扣款阈值而卡住。未知操作保留相关材料，其他材料可继续使用；同一进程内重新连接会继续核对，不按超时直接清空记录。

农田播种发送前复查空地，等待业务回包后再核对地块作物与完整库存，避免补货掩盖种子扣减而一直等待。结果未知时只保留相关种子和地块，不阻止其他材料的操作；后续读取继续确认，不因超时或重连直接重复播种。日志会区分“已确认”和“等待确认”。

博物馆探宝发送前复查地图、英雄占用和材料需求，派遣后先核对服务器队伍或已领取的关卡进度，再读取完整库存。工厂补产使库存持平或增加时，也能确认旧扣款并恢复贸易港装货；丢回包或重连后会继续核对。尚未确认的探宝仅保留相关材料、地图与英雄，不阻止贸易港使用其他材料，单凭超时或库存下降不会重复派遣。

详细锻造在领取确认后续产，达到下单上限仍可领取；游戏内原生自动锻造已开启的工厂会跳过。装备分解与海兽放生只处理所选品质中闲置、未养成的对象，工具无法读取游戏客户端保存在本地的锁定标记。

### 世界与挑战

| 功能 | 行为与限制 |
| --- | --- |
| 舰队优先级 | 默认按城战、首杀、世界 Boss、巨轮跟随、普通巨轮、联盟情报顺序检查，可调整顺序。行军、战斗、维修、驻外和结果待确认的舰队会保留占用 |
| 海盗首杀 | 查看三类下一档目标、编队、首杀奖励和战力对比；可单次派遣或手动启动连续推进。按本人的首杀确认逐级推进，战败、耐久或预算不足时停止，重启后不自动恢复 |
| 海盗日常扫荡 | 与首杀独立，选择种类后使用已首杀的最高等级；三种海盗共用免费次数，无需舰队，不消耗汽油。日常任务达标后仍能用剩余次数；所选种类无目标时等待，不自动降级或换种类 |
| 世界 Boss 首战 | 默认关闭。服务端当天参与次数为 0 时派一支合格空闲舰队，可选舰队、最低耐久和汽油保留；未选舰队时允许任意合格舰队。派遣确认不表示已造成伤害或拿到奖励，伤害奖励另行领取 |
| 万吨巨轮 | 支持打满即停或每次参与、个人/整体进度限制、反复攻占、名单跟随、奖励过滤、避战、外盟权限及出征/汽油/维修限制。跟随名单是派遣条件，避战优先；推送会唤醒调度，抵达时间以游戏为准 |
| 城战接续 | 默认按服务器 VIP 的原生委任额度等待用尽后接续。原生委任次数可设为 -1（按 VIP 规则）、0（关闭所选舰队的原生委任并由工具立即接续）或 N（原生先用 N 次后关闭开关接管）；关闭结果会回读确认。不宣战、不改变集结目标。可跟随本盟已宣战目标或指定城市，按本盟现场排队、当前交战和已同步在途舰队总数选城：相差 0–9 队时选较近目标，差 10 队及以上时优先人少的城市；数量无法确认时跳过 |
| 战后维修 | 复用已启用城战或巨轮的自动维修设置与所选舰队，空闲后普通维修至满耐久，不要求已有下一目标或仍处于城战时段。同一舰队采用优先级较高来源的维修参数，共用对应汽油保留和日预算 |
| 联盟情报 | 保留原有领奖、派舰和维修开关；详细配置可选舰队、类型、耐久与汽油限制，并允许使用现有材料完成难民情报。未选舰队时只领奖，不派遣，不开启原生月卡自动 |
| 主线与试炼 | 保留主线连续失败停止、单次挑战和免费扫荡；免费、免广告及钻石扫荡分别控制。额外扫荡需选择副本，并遵守每副本次数、单次费用、试炼预算与总钻石预算 |
| 联盟功能 | 福利领取、材料求助、职级奖励、联盟科技与手动互助入口；自动响应求助只使用订单预留外材料，世界宝藏仅处理允许的目标 |

城战的工具派遣日上限不包含原生委任；原生委任次数设为 0 或 N 且达到接管条件时，工具会关闭所选舰队的原生委任开关，确认关闭后才按工具预算出战。维修与出战共用城战日汽油预算。战后维修使用普通维修，不花钻石或加速器。舰队任务结果未知时保留记录并核对服务端状态；不能仅凭舰队空闲就把未知任务记成成功。

| 走江助力、龙王罗盘广告礼包 | 各 1 | 活动开放时领取 |
| 工厂生产广告加速 | 3 | 每次 30 分钟，优先剩余时间最长的已开工队列，不会为此新开生产 |
| 建筑升级、博物馆展柜广告加速 | 共 3 | 每次 30 分钟，只加速进行中的目标；展柜到期后自动提交完工 |

有免广告权益（VIP 特权或首充记录）的账号与游戏内流程一致，立即领取。

**“无免广告权益时也领取”默认关闭。** 开启后工具提交广告申请，不播放视频，等待设定秒数后直接领奖。这不是游戏客户端的正常流程，服务器可能识别，存在账号处罚风险，需自行评估。等待秒数默认 15，可设 5–120。现有测试记录中，15 秒在 7 个入口成功；5 秒只在藏品招募成功；广告商店 3 秒被拒。试炼扫荡、建筑加速和博物馆加速尚无真实账号验证记录。

无权益模式下，等待期间账号操作队列会被占用，所以整轮挂机每轮最多处理 1 次（挂机收益除外），手动试炼扫荡和手动走江助力不受此限。等待中暂停或断线时不发送领奖；服务器返回“广告未完成”时跳过该入口并冷却 5 分钟；结果未知时保留记录，核对次数后才继续，不重复提交。

### 总览、地图与工具

- **运行概览**：按功能分组显示当前进度和条件，可搜索、筛选异常/受限项。分组展开时保持单列顺序，不改变其他分组位置。角色区服显示游戏内名称（如“海岛1986服”）和 worldId，账号列表与区服列表同样显示名称。
- **世界地图**：只读显示城市、货轮和舰队，支持拖动、Ctrl+滚轮缩放、图层过滤、定位舰队与选中详情，并展示城战、货轮和汽油统计。自动刷新可设 5–300 秒，默认 10 秒，独立于挂机间隔；行军位置按已同步的起终点和时间推算。
- **礼包兑换**：勾选一个或多个账号（默认当前账号，已暂停账号不可选），每批 1–100 个不同礼包码，按换行、逗号、空白或分号拆分去重，各账号分别保存记录并显示进度。账号各自排队，兑换请求跨账号逐个发送。成功、已用或结果未知的码不对该账号重发；连接失败或结果未知只停止该账号的余码，服务器限频时同批尚未发送的账号一起停止。
- **掉线处理**：掉线或被顶号后挂机会停止，不会自动重连，需要在挂机页重新开始。
- **日志与手动入口**：中文业务日志同时输出到网页与 CMD，关闭网页后仍输出轮次、动作和停止原因；网页可按功能或警告/错误筛选，重新打开会回放最近记录。建筑一览保留一键领取、任务奖励检查/领取、一轮海面经营及逐张居民单；英雄装备/阵容、联盟及活动单次操作也继续可用。同一账号与挂机串行执行，发送前复查条件。原始协议日志 `data/protocol.log` 按 5 MB 轮转到 `data/protocol.log.1`，可用 `CW_PROTOCOL_LOG_MAX_BYTES` 调整上限；`CW_DEBUG=1` 才额外向终端输出原始协议。

## 配置与预算

配置编辑器为当前账号保留草稿，导入只进入草稿，点击保存后生效；保存不启动挂机。只读预览按草稿读取真实游戏状态并计算计划，不发送资源操作，运行安排预览无需连接。执行前仍会复查，预览结果可能随游戏状态变化。

已结束的限时活动会从游戏配置、挂机任务列表和运行安排中隐藏，并停止相应自动任务；原开关、参数、导入导出字段和实现代码均保留。服务器再次下发当前开放的对应子活动时，后台按原设置恢复，重新载入配置即可看到对应入口，其他尚未开放的子活动继续隐藏。刷新活动状态不会覆盖未保存的配置草稿。

截至 2026-11-12，已下线截至 11-11 的酆都诡事联动配置，包括走江踏浪、酆都法旨、驱邪除祟、龙王罗盘及联动签到/礼包。海上风采大赛的公告投票期包含 11-12，暂时保留；满减商店延至 11-13，本工具未设置其自动消费入口。周活动、海商王、军备竞赛及按账号或区服开放的活动不受影响。官方时间依据和恢复规则见 [活动配置下线记录](docs/activity-availability.md)。

原有的联盟订单、联盟情报、装备制造、博物馆和海兽开关独立保存。对应详细模块生效时接管同一功能，防止新旧路径重复执行；关闭详细模块后可继续沿用原规则。缺省字段升级时补齐，已有显式开关值不重置。基地总开关只管理基地动作；英雄自动养成还需要同时开启英雄总开关和「随挂机养成英雄」。

**钻石总开关默认关闭**，每日总预算默认 `2000`，钻石保留阈值默认 `0`；日预算为 `0` 时禁止自动花钻石。总开关不会替你开启点金、付费扫荡或购买等项目。各项目限制与总预算同时生效，建筑、工厂等使用加速器时共用保留数量。

配置在 `data/automation-settings.json`，持久用量与防重记录在 `data/automation-usage.json`，按账号保存、北京时间零点换日。发送前先占用预算；明确未发送或拒绝才释放，已发送但结果未知的操作保留占用，带防重键的未知任务跨日继续等待确认。保存配置或重启不会清除这些记录。本工具用量不等于游戏内全部消费，升级前和在游戏里直接进行的消费不计入工具总账。

材料、金币和舰队预留与持久账本配合，避免多个玩法重复使用旧余额。业务确认后仍须取得随后完整的库存或资源快照；读取失败、数据不完整、切号或结果未知时继续保护。联盟互赠及周订单补料在已收到明确回执后，可于后续读取恢复确认；完全丢失回执且没有可归属本次操作的证据时，仍保留防重记录。配置导出只含玩法设置，不含登录凭据或用量账本；账号导出是含凭据的另一项功能。

战报奖励的新旧开关共用同一领取流程与持久防重记录，挂机时任一开关开启即可检查，同时开启也只执行一次。手动活动、单次领奖、挂机和推送共用该记录，任一入口领取结果未知时，后续检查继续等待确认，不会通过另一入口重发。

## 数据与安全

- `data/`：账号、设置、用量账本和本地日志，含登录凭据，不要提交或外发。
- `work/`：游戏协议、配置和素材缓存，不随仓库分发。
- `certificates/`：抓包 CA、目标证书和代理备份，路径按项目位置计算，不依赖盘符；可用 `CW_CA_DIR` 指向其他目录。抓包结束并移除证书后自动清理，选择保留 CA 时保留。
- `src/ui/dist/`：控制台页面构建产物，随源码提交。
- 控制台只监听本机回环地址，没有登录校验；不要把端口直接暴露到公网。
- 账号导出和礼包兑换记录可能包含凭据或账号信息，请留在本机。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm start` | 先构建界面再启动控制台，默认端口 `17321` |
| `.\start-console.cmd` | 启动控制台，不自动打开浏览器，输出地址与实时运行日志，端口 `17323` |
| `.\start-console.cmd url` | 只输出地址 `http://127.0.0.1:17323/` 并保持窗口，不启动控制台 |
| `.\start-console.cmd status` | 只检查抓包 CA 状态，不启动控制台 |
| `npm run build:ui` | 修改 TSX、页面脚本或主题样式后生成页面与样式 |
| `npm test` | 先构建界面，再依次执行 core、progression、extra 三组自检 |
| `npm run test:core` | 核心协议、日常、原有玩法、阵容和掉线处理回归 |
| `npm run test:progression` | 装备、情报、联盟订单、博物馆、海兽、藏品、资源预留和迁移接线回归 |
| `npm run test:extra` | 详细配置、活动、调度、战后维修、城战/锻造、礼包与地图等额外回归 |
| `npm run test:capture` | 原始抓包、代理、锁和抖音 CLI 回归 |
| `npm run test:wechat` | 微信抓包与登录 CLI 回归 |
| `npm run test:wxapkg` | 微信小游戏包解密与解包回归 |
| `npm run sync-config` | 从本机微信缓存同步配置表到 `work/` |
| `npm run sync-art` | 同步游戏素材；缺图时可加 `-- --fetch` 从 CDN 补齐 |
| `npm run capture:douyin` | 单独采集电脑版抖音登录样本 |
| `node src/app.mjs actions` | 查看协议操作目录 |
| `node src/app.mjs probe` | 连接并读取探测信息 |

`npm test` 需要本机可读取游戏协议包；没有协议缓存时，先在电脑版微信打开一次游戏，或设置 `CW_PROTO_BUNDLE` 指向自己的 `_src_chunks_.wxapkg` 或解包后的 `game.js`。
